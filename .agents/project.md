# Project #3: Medication Demand Prediction and Restocking Recommendation API

## Context
Efficient inventory management is a major challenge in the pharmaceutical sector. Poor anticipation of demand can lead to stock shortages, missed sales opportunities, or overstocking of low-turnover products. Predictive models based on historical sales, purchases, and stock movements can support better decision-making and improve the quality of inventory planning.

## Project Description
The objective of this project is to develop a predictive service capable of analyzing historical pharmacy-related data in order to estimate future medication demand and generate restocking recommendations. The system should use past sales, purchase records, and stock levels to identify consumption patterns and support decisions regarding which products should be replenished and which should not be prioritized.
The final solution should not be limited to a forecasting model, but should be implemented as an API-based service that can be integrated into external information systems. This project combines data analysis, machine learning for forecasting, and service-oriented software development in a real inventory management use case.

## Main Objectives
- Study demand forecasting and stock management problems in the pharmaceutical domain
- Analyze historical inventory, purchase, and sales data
- Develop models for demand prediction and restocking support
- Generate structured recommendations for inventory management
- Expose the final system through an API

## Expected Deliverables
- Analysis of the business and data context of demand prediction
- Preparation and structuring of historical stock and sales data
- Development of forecasting and recommendation models
- Implementation of an API service for prediction and decision support
- Experimental evaluation of the proposed approach
